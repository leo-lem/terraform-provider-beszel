# Gateway

A lightweight, production-inspired API gateway written in Go.

Gateway sits in front of backend services and provides common infrastructure capabilities such as request routing, authentication, logging, metrics, and middleware. Rather than aiming to replace mature solutions like Kong or Traefik, the project focuses on a clean architecture, idiomatic Go, and the core concepts behind modern API gateways.

## Goals

* Build a polished backend infrastructure project in Go.
* Explore the design of reverse proxies and HTTP middleware.
* Demonstrate production-oriented software engineering.
* Showcase AI-native software development with Claude Code.

## Core Features

* Reverse proxy
* Configurable routing
* Authentication
* Request logging
* Metrics
* Health checks
* Middleware architecture
* Docker & GitHub Actions
* Comprehensive tests

## Stretch Goals

* Rate limiting
* Circuit breaker
* Retry policies
* Load balancing
* Hot configuration reload
* Admin API
* Plugin system
